# Whisper Note

一个自己用的录音 + 实时语音转文字小应用。支持中文、英文，以及一句话里中英混着说。

**默认完全在本机识别：不联网、不需要 API Key、不产生任何费用。** 语音识别模型下载一次后存在设备里，之后断网也能用。

它是一个网页应用（PWA）：不用上架 App Store，用浏览器打开后「添加到主屏幕」，就会像普通 App 一样有图标、全屏运行。同一套代码可以在 iPhone、Mac、安卓、鸿蒙上使用。

线上地址：https://pengchenglai.github.io/whisper-note/

## 功能

- **实时转写**：边说边逐字出字，停顿一下这一句就定稿。
- **录音保存**：整段录音同时保存，可以回放、导出。
- **中英混合**：中文、英文、混着说都可以。
- **导入音频**：把已有的录音文件转成文字。
- **笔记管理**：改标题、改文字、搜索、复制、分享、导出 TXT 或录音文件、删除。
- 屏幕常亮、暂停/继续、深色模式、离线可用。

## 装到设备上

- **iPhone**：用 Safari 打开线上地址 → 底部「分享」按钮 → 「添加到主屏幕」。
- **安卓 / 鸿蒙**：用浏览器打开 → 菜单里的「添加到主屏幕」或「安装应用」。
- **Mac**：Safari 打开 → 菜单「文件 › 添加到程序坞」；或用 Chrome 地址栏右侧的安装按钮。

第一次点录音时，应用会询问是否下载识别模型（建议连 Wi-Fi），并请求麦克风权限。

## 本机识别模型

在「设置」里可以选两个模型，手机上同一时间只保留一个：

| 模型 | 下载大小 | 应用总占用 | 特点 |
| --- | --- | --- | --- |
| 轻巧（默认） | 约 60MB | 约 75MB | 出字快，适合手机；没有原生标点（按停顿自动补句号）；中英频繁切换时会漏词或听错 |
| 精准 | 约 170MB | 约 185MB | 自带标点和大小写，中英混说明显更准；更吃性能和内存，适合电脑和较新的手机 |

「应用总占用」包含约 13MB 的识别引擎，不含你自己的笔记和录音。

识别引擎是开源项目 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 的 WebAssembly 版，模型出处见 [local-asr/NOTICE.md](local-asr/NOTICE.md)。

## 可选：云端识别

如果想要更高的准确度，可以在「设置 › 服务商」里改用云端服务。这时需要你自己到对应的开发者后台申请 API Key（ChatGPT 会员、豆包 App 账号不能直接用），录音会直接发给你选的服务商：

| 服务商 | 说明 |
| --- | --- |
| OpenAI（`gpt-transcribe`） | 按用量付费 |
| Groq（`whisper-large-v3`） | 有免费额度 |
| 硅基流动（`SenseVoiceSmall`） | 国内网络可直连 |
| 豆包 / 火山引擎 | 国内网络可直连；要填旧版控制台的 APP ID + Access Token |
| 自定义 | 任何兼容 OpenAI `/audio/transcriptions` 的接口 |

Claude 不能用作转写服务：Anthropic 的 API 不接受音频输入。

## 使用上要知道的几件事

- **录音时保持屏幕亮着、停留在应用里。** iPhone 锁屏或切到别的 App 时，系统会掐掉网页的麦克风，应用会自动暂停，回来后点 ▶ 继续。这是网页应用相对原生 App 的主要限制。
- **数据只在本机。** 笔记、录音、模型都存在这台设备的浏览器里，不会在设备之间同步；清除网站数据或删除主屏幕图标会一并清掉。重要内容请及时导出。
- **本机模型比云端大模型小得多**，准确度有差距，带口音、环境嘈杂、专业术语多的时候更明显。
- 本机识别导入音频文件时，限 16MB 以内。

## 在电脑上预览 / 改代码

电脑上装有 Python 的话，在这个文件夹里运行：

```
python serve.py
```

然后用浏览器打开 http://localhost:8377 。（`localhost` 是特例，不需要 https 也能用麦克风。）

把改动推送到 GitHub 仓库的 `main` 分支后，线上地址约一分钟后自动更新。**改了任何文件都要把 `sw.js` 里的版本号加一**，否则已经装到手机上的应用会继续用旧文件。

## 文件说明

```
index.html            页面入口
styles.css            样式
manifest.webmanifest  「添加到主屏幕」所需的应用信息
sw.js                 离线缓存
icons/                应用图标
js/app.js             界面：列表、录音、笔记详情、设置
js/session.js         一次录音会话：把语音交给识别引擎、拼接文字、自动存盘
js/recorder.js        麦克风采集、降采样、按停顿自动断句
js/pcm-worklet.js     音频线程里的采集模块
js/local-engine.js    本机识别：模型下载状态、和后台线程通信、整理识别结果
js/transcriber.js     整段音频转文字（本机或云端接口）
js/settings.js        设置与服务商预设
js/db.js              本机存储（IndexedDB）
local-asr/            本机识别引擎（sherpa-onnx）、后台线程 worker.js、两个模型
tools/                打包模型用的脚本
serve.py              电脑本地预览用的小服务器
```
