# Whisper Note

一个自己用的录音 + 实时语音转文字小应用。支持中文、英文，以及一句话里中英混着说。

它是一个网页应用（PWA）：不用上架 App Store，用手机浏览器打开后「添加到主屏幕」，就会像普通 App 一样有图标、全屏运行。同一套代码可以在 iPhone、Mac、安卓、鸿蒙上使用。

## 功能

- **实时转写**：边说边出字。停顿一下，这一句就定稿；说话过程中先显示灰色的预览文字。
- **录音保存**：整段录音同时保存，可以回放、导出。
- **中英混合**：默认按「中文 + 英文混说」识别，也可以切换成只中文、只英文或自动检测。
- **导入音频**：把已有的录音文件（m4a、mp3、wav 等，25MB 以内）转成文字。
- **笔记管理**：改标题、改文字、搜索、复制、分享、导出 TXT 或录音文件、删除。
- **专有名词提示**：把容易听错的人名、术语填进设置里，识别更准。
- 屏幕常亮、暂停/继续、转写失败一键重试、深色模式、断网也能打开看旧笔记。

## 它是怎么工作的

手机负责录音和断句，每说完一句就把这一小段音频直接发给你选的语音识别服务，拿回文字。没有中间服务器；笔记、录音和 API Key 都只存在你自己的设备上。

所以需要一个语音识别服务的 **API Key**（在应用的「设置」里填）：

| 服务商 | 特点 | 申请地址 |
| --- | --- | --- |
| OpenAI（默认，模型 `gpt-transcribe`） | 中英混说效果最好；按用量付费，需要绑定付款方式 | https://platform.openai.com/api-keys |
| Groq（模型 `whisper-large-v3`） | 有免费额度，速度很快 | https://console.groq.com/keys |
| 硅基流动（模型 `SenseVoiceSmall`） | 国内网络可以直连 | https://cloud.siliconflow.cn/account/ak |
| 自定义 | 任何兼容 OpenAI `/audio/transcriptions` 的接口 | — |

填好之后点「测试连接」，显示成功就可以用了。

## 装到手机上

手机浏览器只允许 **https 网址** 使用麦克风，所以要先把这个文件夹放到一个 https 的静态网站上（免费的就行），拿到网址后：

- **iPhone**：用 Safari 打开网址 → 底部「分享」按钮 → 「添加到主屏幕」。
- **安卓 / 鸿蒙**：用浏览器打开 → 菜单里的「添加到主屏幕」或「安装应用」。
- **Mac**：Safari 打开 → 菜单「文件 › 添加到程序坞」；或用 Chrome 地址栏右侧的安装按钮。

第一次录音时会弹出麦克风权限，选「允许」。

### 放到网上的两种办法

1. **GitHub Pages**：把这个文件夹推到一个 GitHub 仓库，在仓库 Settings › Pages 里选择从 main 分支发布，得到 `https://用户名.github.io/仓库名/`。
2. **Netlify Drop**：打开 https://app.netlify.com/drop ，把整个文件夹拖进去，马上得到一个网址（注册账号后才会长期保留）。

网址是公开的，但别人打开只是一个空白的应用——你的笔记、录音和 Key 都在你自己的手机里，不在网站上。

## 在电脑上预览

电脑上装有 Python 的话，在这个文件夹里运行：

```
python serve.py
```

然后用浏览器打开 http://localhost:8377 。（`localhost` 是特例，不需要 https 也能用麦克风。）

## 使用上要知道的几件事

- **录音时保持屏幕亮着、停留在应用里。** iPhone 锁屏或切到别的 App 时，系统会掐掉网页的麦克风，应用会自动暂停，回来后点 ▶ 继续。这是网页应用相对原生 App 的主要限制。
- **数据只在本机。** 不会在设备之间同步；清除浏览器网站数据、或者删除主屏幕图标，都会把笔记清掉。重要内容请及时导出。
- **「实时」是按句的。** 停顿约 0.8 秒后这一句定稿（可在设置里调快慢），通常 1 秒左右出字，取决于网络。
- **费用。** 语音识别按音频时长计费，由你选的服务商收取；开着「边说边预览」会多用一些额度，可以在设置里关掉。
- 中英混说的准确度取决于所选模型，没有哪个模型能保证百分之百。

## 文件说明

```
index.html            页面入口
styles.css            样式
manifest.webmanifest  「添加到主屏幕」所需的应用信息
sw.js                 离线缓存（改了代码后把里面的版本号加一，手机才会更新）
icons/                应用图标
js/app.js             界面：列表、录音、笔记详情、设置
js/session.js         一次录音会话：排队转写、拼接文字、自动存盘
js/recorder.js        麦克风采集、按停顿自动断句
js/pcm-worklet.js     音频线程里的采集模块
js/transcriber.js     调用语音识别接口
js/settings.js        设置与服务商预设
js/db.js              本机存储（IndexedDB）
serve.py              电脑本地预览用的小服务器
```
